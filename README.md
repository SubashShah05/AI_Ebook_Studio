# AI Ebook Studio 📚✨

AI Ebook Studio is a full-stack web application built using the MERN stack. It leverages the power of Google Gemini AI to help users automatically architect, structure, write, and export complete multi-chapter digital books from a single topic prompt.

## 🌐 Live Demo
**https://ai-ebook-studio.vercel.app/**

## 🚀 Features

- **AI Content Pipeline Architect:** Automatically computes structured multi-chapter layouts using Google Gemini AI with strict schema configurations.
- **Interactive Drag-and-Drop Dashboard:** Easily reorder chapters with an instant cloud-synced bulk database rewrite pipeline.
- **Live Markdown Workspace:** Features on-demand AI draft generation, real-time reader preview rendering, and direct file compilation.
- **Flexible Document Export:** Instantly download finished assets as print-ready PDFs or standard Markdown (`.md`) files.
- **Secure Authentication:** Implements JWT-based session tracking with Axios request interceptors.
- **Persistent Theme Engine:** Seamlessly toggle between Light and Dark modes to reduce eye strain during long writing sessions.

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, Axios
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose Object Data Modeling (ODM)
- **AI Integration:** Google Gemini API

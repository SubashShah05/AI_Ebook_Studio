🛠️ How it works technically (In Simple English)
State Management: When a user clicks the moon/sun icon, a React state (theme or darkMode) toggles between true and false.

Tailwind CSS Integration: The app dynamically adds or removes the .dark class from the root HTML element (document.documentElement.classList).

Persistence (Local Storage): To make the user experience premium, the selected theme is saved in localStorage. This means if a user reloads the page or logs back in later, the app remembers their favorite look automatically.

"Since this is a book-writing platform where authors spend hours reading and typing text, I added this feature to reduce eye strain during long night writing sessions and to provide a modern, highly responsive user experience."
